Was hier wirklich passiert

Echtes DSP in Echtzeit: Obertonsynthese bis 16 kHz, Sub-Bass bis 30 Hz, Ent-Rauschen, Ent-Knacksen und ein dynamischer Resonanz-Tilger — berechnet auf deinem Gerät, nicht in einer Cloud.

Privat by design

Es gibt keinen Server. Keine Uploads, keine Cookies, kein Tracking, keine Analyse-Tools. Schließe den Tab — alles ist weg.

Kostenlos & offen

Statisches HTML, CSS und JavaScript — läuft auf GitHub Pages, ohne Build, ohne Abo. Der Quellcode ist frei einsehbar.

Stapelverarbeitung

Beliebig viele Dateien auf einmal — eine nach der anderen, damit dein Speicher atmet. Am Ende ein ZIP mit allen Ergebnissen.
